README
======

Overview
--------

This repository provides the official code implementation for the paper "[Paper Title]". The code performs cross-subject EEG classification with differential entropy (DE) features, subject selection, and Model-Agnostic Meta-Learning (MAML).

The repository contains three Python scripts:

1. code1_Subject_amount_select.py: A lightweight ShallowCNN baseline for a single target subject. It trains on all remaining subjects and evaluates the selected target subject. The current implementation uses configuration variables inside the script and does not perform an automatic subject-number search.
2. code2_subject_selected.py: Selects the most similar source subjects for each target subject using cosine similarity on flattened DE features. It saves the selected subject indices and similarity weights as .mat files.
3. code3_meta_learning.py: Trains a Deep4Net model with MAML on the selected support subjects and evaluates rapid adaptation to each query subject. It supports either an Excel-based support-subject map or manually specified subject lists.

Data Preparation
----------------

The scripts are designed for preprocessed DE-feature data. The default paths in the source code are Windows examples and should be changed before running the scripts.

For .npz files used by code2_subject_selected.py and code3_meta_learning.py:

- The DE feature array is stored under the key DE by default.
- The class label array is stored under the key label by default.
- The expected feature shape is (n_trials, n_channels, n_time).
- The label length must equal the number of trials.

code2_subject_selected.py uses the following filename template by default:

    DE_Sub_S2_{subject}.npz

code3_meta_learning.py uses the following filename template by default:

    DE_Sub_S1_{n}.npz

The script can also load epoch-level .npz files named like:

    DE_Sub{subject}_epoch_{index}data.npz

code1_Subject_amount_select.py loads .mat files containing:

- data: EEG feature or signal array
- label: class labels

The current script expects the target subject ID and data folder to be edited directly in the source code.

Note: Dataset files are not included in this repository. Please obtain the data from the official source and comply with its access and privacy requirements.

Usage
-----

1. ShallowCNN Baseline

Open code1_Subject_amount_select.py and update the following variables:

    data_folder = r"E:\MATB36-source\MATB_36_epoch2"
    TEST_SUBJECT = 8

Then run:

    python code1_Subject_amount_select.py

The script trains a ShallowCNN model on all subjects except TEST_SUBJECT, evaluates the model on the target subject, and prints the final accuracy.

2. DE-Based Source-Subject Selection

Run code2_subject_selected.py from the repository root:

    python code2_subject_selected.py \
        --num_subjects 15 \
        --top_k 11 \
        --de_feature_root "E:\MATB15-source\15-2-DE" \
        --de_file_format "DE_Sub_S2_{subject}.npz" \
        --de_feature_key DE

The script computes cosine similarity between flattened DE feature vectors and selects the top_k most similar non-self subjects for every target subject.

Generated files:

    count/final_subj_1.mat
    count/final_subj_2.mat
    ...
    count/final_subj_N.mat
    count/all_topk_result.mat

Each final_subj_<id>.mat file contains:

- top_similar_subjects: selected subject IDs (1-based)
- top_k: number of selected subjects
- weights: similarity-based weights for all subjects

3. Deep4Net + MAML Classification

code3_meta_learning.py is configured through variables in the source file rather than command-line arguments.

3.1 Select the support-subject mode

Excel-based support map:

    USE_EXCEL_SUPPORT_MAP = True
    SUPPORT_MAP_EXCEL_PATH = r"E:\MATB15-source\15-1-DE\SSAS-DE-15-1.xlsx"

The Excel file is expected to have no header row:

- Column 1: query/target subject ID or filename.
- Remaining columns: support subjects for that query subject.

Manual support-subject mode:

    USE_EXCEL_SUPPORT_MAP = False
    QUERY_SUBJECT = "DE_Sub_S1_14.npz"
    SUPPORT_SUBJECTS = [
        "DE_Sub_S1_1.npz",
        "DE_Sub_S1_2.npz",
        "DE_Sub_S1_3.npz",
    ]

The script automatically removes the query subject from the support list to prevent subject-level information leakage.

3.2 Configure the data and run range

Update the data directory:

    DATA_CONFIG["data_root"] = r"E:\MATB15-source\15-1-DE"

Optional query-subject filters:

    RUN_QUERY_SUBJECTS_ONLY = ["DE_Sub_S1_14.npz"]
    RUN_LAST_N_QUERY_SUBJECTS_ONLY = None
    RUN_QUERY_START_INDEX = None

3.3 Run training and evaluation

    python code3_meta_learning.py

The script performs MAML meta-training on the support subjects and evaluates rapid adaptation on each selected query subject.

Output files are saved under DATA_CONFIG["data_root"]:

    MAML_Test_Results_Improved_All15.xlsx
    MAML_Summary_Improved_All15.xlsx

The subject-level result file includes accuracy, loss, macro F1 score, FLOPs, trainable parameters, and average epoch time. Random seeds are fixed to 42 for reproducibility.

Key MAML Parameters
-------------------

Parameter          Description                                           Default
---------          -----------                                           -------
meta_lr            Outer-loop meta-learning rate                         2e-4
inner_lr           Inner-loop learning rate during meta-training          1e-3
test_inner_lr      Fine-tuning learning rate during evaluation             8e-4
meta_batch_size    Number of meta tasks per meta-update                   11
inner_steps        Number of inner-loop updates during meta-training       5
test_inner_steps   Number of adaptation steps during evaluation            40
meta_epochs        Maximum number of meta-training epochs                  300
way                Number of classes per meta-task                        3
support_ratio      Fraction of samples used as the support set            0.2
test_num_splits    Number of repeated evaluation splits                   6
second_order       Whether to use second-order MAML gradients             False
weight_decay       Weight decay for the meta-optimizer                    5e-5
meta_grad_clip     Gradient clipping threshold                            1.0
model_drop_prob    Dropout probability in Deep4Net                        0.4

Method Overview
---------------

1. Source-Subject Similarity Selection: Flattened DE features are normalized and compared using cosine similarity. The top-k most similar non-self subjects are selected for each target subject.
2. Meta-Task Construction: The selected support subjects are used to construct MAML tasks. Each task contains a support set and a query set sampled from the same subject.
3. MAML Training: The inner loop performs task-specific updates on the support set. The outer loop optimizes the initialization using query-set performance.
4. Target-Subject Adaptation: The learned initialization is fine-tuned on the query subject and evaluated on its remaining samples.

Experimental Results
--------------------

On the MATB-15, the proposed method achieves accuracy 68.33% , F1 score 65.59%.
